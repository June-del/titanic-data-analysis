# Titanic Data Analysis Project
This is my first data analysis project using Python.  
I worked on the Titanic dataset to understand how data analysis and visualization work.

---

# What I did
- Loaded the Titanic dataset using Pandas
- Checked and explored the data
- Handled missing values
- Created charts to understand patterns in the data
- Learned how to use Matplotlib and Seaborn for visualization

---

# Visualizations I created

- Survival count (how many survived vs did not survive)
- Age distribution of passengers
- Survival by gender
- Survival by passenger class

# Key insights
- Most passengers did not survive the disaster
- Females had a higher survival rate than males
- First-class passengers had better chances of survival
- Most passengers were between 20 and 40 years old
